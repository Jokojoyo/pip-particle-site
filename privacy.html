Privacy Policy

Last updated: 2026-09-19

Pip & Particle Publisher ("the tool") is a personal automation used solely by the owner of the Pip & Particle social media accounts to publish their own videos.

What data is processed

  • OAuth access tokens for the owner's own TikTok, YouTube, Instagram and Facebook accounts.
  • Basic profile information returned by those platforms (account id, display name, username) to confirm which account is connected.
  • The owner's own video files and captions.

Where it is stored

Tokens and logs are stored only on the owner's personal computer. Video files are temporarily copied to a private cloud storage bucket owned by the account owner so that platform APIs can fetch them, and are deleted after publishing.

What is not done

No data is collected from any other person. Nothing is sold, shared, or used for advertising or analytics. No cookies are set by this website.

Deleting data

The owner can revoke the tool's access at any time from each platform's connected-apps settings; local tokens are then deleted.

YouTube API Services

The tool uses YouTube API Services to upload the owner's own videos to the owner's own YouTube channel. By using it, the account owner agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

  • Data accessed: the tool requests the youtube.upload and youtube.readonly permissions only, to upload videos and to read the name of the connected channel. It does not collect, store or share any other YouTube data, and it does not access data of any other user.
  • Storage: the only YouTube-related data kept is the OAuth token, stored in a file on the owner's personal computer. Nothing is stored on a server, and nothing is shared with third parties.
  • Revoking access: the owner can revoke the tool's access to their Google account at any time via the Google security settings page; the local token is then deleted.

Contact

Questions: contact the account owner via the Pip & Particle TikTok profile (@pip.and.particle).
